# flybywireless-xplm-macros

Procedural macros for [`flybywireless-xplm`](https://crates.io/crates/flybywireless-xplm):
`#[plugin(...)]` and `#[derive(DataRefContainer)]`, re-exported through the
`xplm` crate rather than depended on directly.

Published on crates.io as `flybywireless-xplm-macros`. See the
[workspace README](https://github.com/wegylexy/XPLM) for usage.
